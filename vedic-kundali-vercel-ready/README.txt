VEDIC KUNDALI GENERATOR - VERCEL DEPLOYMENT

This is a static HTML project. No build command or output directory is required.

Deploy with Vercel:
1. Extract this ZIP file.
2. Open https://vercel.com/new and sign in.
3. Choose "Deploy" / "Deploy a project" and import a Git repository,
   OR use Vercel CLI from this extracted folder.
4. If prompted for framework, choose "Other".
5. Build command: leave blank.
6. Output directory: leave blank (project root).
7. Deploy.

The website entry point is index.html.

vedic_kundali_generator.html was used as index.html. The stray GitHub-link
